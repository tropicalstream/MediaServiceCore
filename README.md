# MediaServiceCore

MediaServiceCore is a fork of an unofficial Java API for YouTube, providing the network and data layer behind a YouTube-compatible media client. The `rayneo-0.4` branch carries the RayNeo X3 Pro AR glasses customizations on top of the upstream project: the shared-preferences interface is pinned to an older, app-compatible API rather than tracking the newer upstream module, and the fork is kept current with upstream fixes to playback tokens, playlist handling, search, and subtitles.
